# Screenshot and submission visual guide

Use three screenshots. Do not overload judges with too many images.

## Screenshot 1 — Hero / full dashboard

**Capture:** the full TowkAI OS screen using the Hawker Centre background.

Make sure the following are visible:
- “What this app does” panel
- project list
- active agent list
- centre agent map
- inspector
- approval queue

**Caption:**

> One visual control centre for a solo founder to manage projects, agents, tasks and approvals.

This should be the first and main screenshot because it explains the whole product.

## Screenshot 2 — Agents executing a mission

**Capture:** click **RUN DEMO** and take the screenshot while agents are moving and speech bubbles are visible.

Make sure the live console contains several new events.

**Caption:**

> Specialist agents work in parallel across research, product, growth and operations while the founder sees progress in real time.

This screenshot proves the product is interactive rather than a static mock-up.

## Screenshot 3 — Founder control and approval

**Capture:** select one agent so the inspector is populated, then keep the approval queue visible.

Make sure the following controls can be seen:
- PAUSE
- REASSIGN
- APPROVE
- STOP
- editable task input
- CHOP / SEND BACK

**Caption:**

> The founder can inspect, redirect and approve every agent. Nothing ships without human judgment.

## Optional fourth screenshot — theme flexibility

Use only if the submission permits more visuals.

**Capture:** the Gardens by the Bay or Trading Floor background.

**Caption:**

> Switchable Singapore-themed environments make invisible agent work memorable and legible.

## Best order in a pitch deck or social post

1. Full dashboard — “what it is”
2. Agents moving — “how it works”
3. Inspector and approval — “why it is controllable”
4. Optional alternate theme — “why it is memorable”

## 15-second screen recording flow

1. Start on the Hawker Centre map.
2. Click Dealmaiker in the sidebar.
3. Click Trading Floor background.
4. Click RUN DEMO.
5. Click Scout.
