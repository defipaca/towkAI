## Project Introduction
Towkay ("boss" in Hokkien) is a gamified command centre where a founder runs a one-person company like a Singapore hawker centre: every stall is an AI agent, and the founder is the towkay. The founder enters one business goal, an orchestrator splits it into work chits, and four specialist stalls handle market research, BD outreach, growth loops and lead-generation funnels in parallel. Every output comes back to a human approval counter, where the founder can “Chop & Serve” it or send it back with feedback. A ledger records every dispatch, revision and approval. The specialist stalls are based on workflows from products I have already built—Flywheel, Dealmaiker, Rocketo and IgnAIte—so the interface demonstrates how existing agents can be operated as one legible company.

## Project Innovation (Related to AI)
1. **Agent orchestration as a visible operating system:** one business goal is decomposed into typed work chits and routed to specialist agents, each with a clear role, status and queue.
2. **Human judgment as a first-class primitive:** no output is treated as complete until the founder explicitly approves it. Rejected work carries structured feedback into a redo loop.
3. **Spatial, game-like trust interface:** the hawker-centre metaphor makes parallel agent activity understandable at a glance, replacing scattered chats and opaque JSON logs.
4. **Workflow composability:** the MVP maps to real workflows from Flywheel, Dealmaiker, Rocketo and IgnAIte. The next stage turns each stall into an installable agent or API integration.
5. **Auditability:** an append-only ledger records dispatch, completion, revision and approval events, providing a foundation for accountable agent operations.

## Pain Point Solved
The One Person Company bottleneck is no longer access to AI capability; it is legibility, coordination and control. Solo founders currently manage agents across disconnected chat threads and tools, with no unified view of what is running, no consistent approval gate before output reaches customers, and no clear audit trail of what happened. This makes it difficult to trust agents or scale beyond a few concurrent workflows. Towkay gives one operator a single command centre, visible agent queues, a mandatory human approval counter and a complete decision ledger—making “one founder plus agents equals a company” operable rather than aspirational.

## Current Development Progress
A working, responsive MVP was built solo for BUIDL_OPC_SG_0712. The demo accepts a business goal, dispatches four specialist agents in parallel, visualises live cooking states, returns outputs as review chits, supports approval and feedback-driven redo loops, and records all activity in a ledger. It is a zero-build static app that runs without an API key, making it reliable for judging and offline demonstration. The next milestones are to connect each stall to the live Flywheel, Dealmaiker, Rocketo and IgnAIte workflows; add persistent agent memory and multi-order scheduling; and launch an installable third-party stall marketplace.
