# OpenArena submission copy

## Project Name
TowkAI OS

## Project Introduction
TowkAI OS is a live, gamified pixel-art AI agent IDE. It gives a solo founder one visual control room to see what every AI agent is doing across projects, track progress and recent updates, and intervene when needed. Pixel agents move between research, build, design, outreach, review and operations rooms according to their actual activity state. The founder can click any agent to inspect its task, progress, priority, output, ETA and recent updates, then pause, reprioritise, redirect, block or approve it. A live activity feed shows what changed recently, while Founder Attention surfaces blocked and review-ready work. The MVP adds an interactive game layer—XP, quests, achievements, speed controls, animated effects and Singapore-themed scene skins—to make complex parallel AI work legible, engaging and fun without losing operational usefulness.

## Project Innovation (Related to AI)
1. AI workforce visibility as the core product, rather than another chat or prompt interface.
2. Spatial, activity-driven representation of agent work using rooms, movement, bubbles and status changes.
3. Real-time founder control over task, priority, pause/resume, review, blocking and approval states.
4. Exception-first supervision through Founder Attention and next-best-action guidance.
5. Gamification through XP, quests, achievements and progress feedback that encourages active supervision.
6. Scene skins that make the same operational system memorable and locally distinctive.

## Pain Point Solved
As one-person companies adopt more AI agents, work becomes fragmented across chat threads, coding agents, automation tools and dashboards. Founders lose visibility into who is working, what changed, what is blocked and where human judgment is required. TowkAI OS turns that invisible agent sprawl into one understandable, controllable operating picture.

## Current Development Progress
A functional static MVP is complete. It includes project and agent views, live autonomous progress simulation, activity-based pixel movement, blocked/review alerts, agent inspector, recent updates, output previews, founder controls, priority adjustment, task editing, live activity feed, Founder Attention queue, speed controls, random task assignment, XP, quests, achievements, animated effects, keyboard shortcuts, guided onboarding and three Singapore-themed scene skins. The next step is connecting the interface to real agent runtimes and event streams.

2. Usage-based orchestration and observability fees.
3. Premium integrations with coding agents, AI tools, CRMs and workflow platforms.
4. White-label control rooms for agencies, venture studios and AI-native teams.
5. Marketplace revenue from installable agent modules and workflow packs.
