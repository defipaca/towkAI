## Project Name
TowkAI OS

## Project Introduction
TowkAI OS is a gamified pixel-art AI agent IDE for One-Person Companies (OPCs). The name plays on “towkay,” meaning boss in Hokkien: the founder becomes the towkay supervising an AI workforce.

The product gives one person a single visual command centre to see what every agent is doing across projects, inspect its current task and execution plan, track progress and updates, preview real artifacts, and intervene when needed. Agents move through research, build, design, outreach, founder review and operations zones according to their live state.

The current MVP includes a responsive Agent Inspector with Overview, Plan, Activity, Artifacts and Controls tabs; real artifact preview and revision workflows; project-level filtering; a Founder Attention queue; guided onboarding; real-time simulation; and a public GitHub connector that loads actual repository metadata and recent commits into the Builder agent.

TowkAI makes invisible agent activity visible, understandable and controllable, allowing one founder to operate an AI-powered OPC with confidence.

## Project Innovation (Related to AI)
1. **AI workforce visibility:** one place to see all agents, tasks, progress, blockers, updates and outputs.
2. **Agent IDE interaction model:** each agent has Overview, Plan, Activity, Artifacts and Controls views rather than only a chat box.
3. **Spatial orchestration:** pixel agents move according to live work state, making parallel execution legible.
4. **Artifact-centred supervision:** founders inspect real outputs, approve them or request revision.
5. **Exception-first operations:** blocked and review-ready agents automatically surface in Founder Attention.
6. **Real connector architecture:** the MVP can load actual GitHub repository activity into an agent, demonstrating the adapter model for future coding, research and workflow agents.
7. **OPC-native gamification:** XP, quests, scene skins and interactive pixel activity make supervising an AI workforce intuitive and engaging.

## Pain Point Solved
Founders using multiple AI agents cannot easily answer: Which agents are running? What is each one doing? What changed? What output was produced? What is blocked? Where do I need to intervene?

This work is fragmented across chats, coding tools, automation platforms and dashboards. TowkAI OS provides one operating system for agent visibility, progress, artifacts, approvals and founder control.
